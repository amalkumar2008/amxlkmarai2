## Vercel

1. Upload/push this project to GitHub.
2. Import the repository into Vercel.
3. Add `OPENAI_API_KEY` in Vercel Environment Variables.
4. Add `OPENAI_MODEL` with a model ID available to your OpenAI API account.
5. Redeploy.
6. Open your Vercel URL.

Never put the real API key in GitHub or `public/index.html`.
